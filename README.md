# Lab3-01a_MicroSD_SPI

**Giao tiếp thẻ nhớ MicroSD bằng SPI thuần**

Bài thực hành thuộc Lab3 (CDH & Storage) trong hệ thống CubeSat-LMS:
- Cấu hình chân SPI phần cứng vệ tinh: CS=13, SCK=18, MISO=19, MOSI=23
- Khởi tạo và đọc thông tin dung lượng thẻ nhớ qua SD.h
- Thực hiện thao tác ghi và đọc file kiểm tra tính toàn vẹn dữ liệu
